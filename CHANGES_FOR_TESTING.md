# Custom IPTV Player — work in progress

## Implemented in this source snapshot
- Added Electric Blue, Slate Grey, Ocean Glass, and Dark Indigo to the theme picker.
- Kept all three existing themes.
- Used original ynoTV CSS accent and background colour values in Flutter's colour scheme.

## Not implemented yet

- Local M3U file picker and persistence.
- Multiple independent EPG URL management.

## Testing
Flutter SDK is not installed in this build environment, so this is an uncompiled source snapshot, **not a tested APK**. Build and test on a separate installation before replacing your working player. The original uploaded ZIP was not changed.
